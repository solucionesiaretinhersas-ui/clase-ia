# Logos

Coloca aquí el logo oficial de Google AI Studio con el nombre `ai-studio.svg` (o `ai-studio.png`).
La app lo mostrará en la portada, la estación de AI Studio y el menú del celular.
Si el archivo no existe, se usa un ícono genérico.

Descarga el logo desde los recursos de marca de Google y respeta sus condiciones de uso.
